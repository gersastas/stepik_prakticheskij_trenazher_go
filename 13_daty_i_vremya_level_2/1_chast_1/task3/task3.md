У вас есть переменные `h`, `m`, `s`, которые содержат входные пользовательские данные.

`h` - часы
`m` - минуты
`s` - секунды

Напишите код, определяет значение с наибольшей продолжительностью и записывает результат в переменную `result`.

**Sample Input 1:**

```
1 | 59 | 3000
```

**Sample Output 1:**

```
1
```

**Sample Input 2:**

```
2 | 300 | 10000
```

**Sample Output 2:**

```
300
```
