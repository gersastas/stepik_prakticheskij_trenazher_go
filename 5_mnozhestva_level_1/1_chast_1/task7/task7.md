У вас есть переменные `A`, `B`, которые содержат входные пользовательские данные.

Напишите код, который объединяет множества A∪B*A*∪*B*, и записывает отсортированный результат в порядке возрастания в переменную `result`.

**Sample Input:**

```
[10, 20, 30] | [1, 2, 3]
```

**Sample Output:**

```
1, 2, 3, 10, 20, 30
```
