У вас есть переменные `A`, `B`, которые содержат входные пользовательские данные.

Напишите код, который находит разность множества A \ B*A* \ *B*, и записывает отсортированный результат в порядке возрастания в переменную `result`.

**Sample Input:**

```
[1, 2, 3, 4, 5] | [6, 7, 8, 9, 0]
```

**Sample Output:**

```
1, 2, 3, 4, 5
```
