У вас есть переменная `A`, которая содержит входные пользовательские данные.

Напишите код, который удаляет все нечетные числа из множества `A` и записывает отсортированный результат в порядке возрастания в переменную `result`.

**Sample Input:**

```
[1, 2, 3, 4, 5, 6, 7]
```

**Sample Output:**

```
2, 4, 6
```
