У вас есть переменные `A`, `e`, которые содержат входные пользовательские данные.

Напишите код, который проверяет есть ли элемент `e` в множестве `A` и записывает логический результат в переменную `result`.

**Sample Input 1:**

```
[1, 2, 3] | 3
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
[1, 2, 3] | 42
```

**Sample Output 2:**

```
false
```
