У вас есть переменные `A`, `B`, которые содержат входные пользовательские данные.

Напишите код, который находит симметрическую разность множеств A△B*A*△*B*, и записывает отсортированный результат в порядке возрастания в переменную `result`.

**Sample Input:**

```
[1, 2, 3, 4, 5] | [8, 7, 3, 2, 1]
```

**Sample Output:**

```
4, 5, 7, 8
```
