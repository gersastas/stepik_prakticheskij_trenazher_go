У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который парсит и заменяет все математические выражения (сложение) в тексте переменой `message` и записывает результат в переменную `result`.

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input 1:**

```
Сумма чисел (3 + 2 = #) и сумма чисел (2 + 2 = #)
```

**Sample Output 1:**

```
Сумма чисел 3 + 2 = 5 и сумма чисел 2 + 2 = 4
```

**Sample Input 2:**

```
Сумма чисел (3 + 2 = #)
```

**Sample Output 2:**

```
Сумма чисел 3 + 2 = 5
```

**Sample Input 3:**

```
Сумма чисел (10 + 2 = #) а также сумма чисел (2 + 2 = #)
```

**Sample Output 3:**

```
Сумма чисел 10 + 2 = 12 а также сумма чисел 2 + 2 = 4
```
