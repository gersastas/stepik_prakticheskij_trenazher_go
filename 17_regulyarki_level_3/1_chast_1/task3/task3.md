У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который парсит и заменяет все математические выражения (сложение, вычитание, умножение, деление) в тексте переменой `message` и записывает результат в переменную `result`.

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input 1:**

```
Калькулятор: 1 + 2 = #, 5 - 3 = #, 2 * 2 = #, 4 / 2 = #
```

**Sample Output 1:**

```
Калькулятор: 1 + 2 = 3, 5 - 3 = 2, 2 * 2 = 4, 4 / 2 = 2
```

**Sample Input 2:**

```
(1 + 2 = #) (2 * 2 = #) (4 / 2 = #) (5 - 3 = #)
```

**Sample Output 2:**

```
(1 + 2 = 3) (2 * 2 = 4) (4 / 2 = 2) (5 - 3 = 2)
```
