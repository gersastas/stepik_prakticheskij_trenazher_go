У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который парсит и заменяет все математические выражения (сложение, вычитание, умножение, деление) состоящие из 3 операндов в тексте переменой `message` и записывает результат в переменную `result`.

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input 1:**

```
Калькулятор: 1 + 1 + 1 = #, 5 - 3 - 1 = #, 2 * 2 * 2 = #, 4 / 2 / 1 = #
```

**Sample Output 1:**

```
Калькулятор: 1 + 1 + 1 = 3, 5 - 3 - 1 = 1, 2 * 2 * 2 = 8, 4 / 2 / 1 = 2
```

**Sample Input 2:**

```
Мой Калькулятор: 2 * 2 * 2 = #, 4 / 2 / 1 = #, 1 + 1 + 1 = #, 5 - 3 - 1 = #
```

**Sample Output 2:**

```
Мой Калькулятор: 2 * 2 * 2 = 8, 4 / 2 / 1 = 2, 1 + 1 + 1 = 3, 5 - 3 - 1 = 1
```
