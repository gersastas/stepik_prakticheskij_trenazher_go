У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который парсит и заменяет все математические выражения (сложение и вычитание) в тексте переменой `message` и записывает результат в переменную `result`.

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input 1:**

```
Сумма чисел (1 + 2 = #) и разность чисел (5 - 3 = #) еще и разность чисел (3 - 2 = #)
```

**Sample Output 1:**

```
Сумма чисел 1 + 2 = 3 и разность чисел 5 - 3 = 2 еще и разность чисел 3 - 2 = 1
```

**Sample Input 2:**

```
Сумма чисел (2 + 2 = #) и разность чисел (10 - 3 = #)
```

**Sample Output 2:**

```
Сумма чисел 2 + 2 = 4 и разность чисел 10 - 3 = 7
```
