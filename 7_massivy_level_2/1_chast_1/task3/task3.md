У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`. 

Напишите код, который возвращает сумму пропущенных четных чисел из массива `data` и записывает результат в переменную `result`.

Например: 

[1,3,5]= 2+4=6[1,3,5]= 2+4=6

[1,5]=2+4=6[1,5]=2+4=6

[1,2,3]=0[1,2,3]=0

**Sample Input:**

```
[1, 3, 5]
```

**Sample Output:**

```
6
```
