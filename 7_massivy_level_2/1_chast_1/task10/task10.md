У вас есть переменные `data`, `order`, которые содержит входные пользовательские данные.

`data` - массив из элементов типа данных `string`. 

`order` - порядок сортировки.

Напишите код, который упорядочивает буквы каждого элемента в массиве `data` в порядке возрастания (**ASC**) или убывания (**DESC**) и создает новый массив.

Новый массив необходимо записать в переменную `result`.

**Sample Input 1:**

```
["кгуде","вгa"] | ASC
```

**Sample Output 1:**

```
["гдеку","aвг"]
```

**Sample Input 2:**

```
["абв","где"] | DESC
```

**Sample Output 2:**

```
["вба","едг"]
```

**Sample Input 3:**

```
["буря", "море", "небо"] | DESC
```

**Sample Output 3:**

```
["яурб","роме","онеб"]
```
