У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов произвольного типа данных.

Напишите код, который сортирует массив `data` особым способом. Результатом должен быть новый массив, отсортированный в порядке возрастания (число, буква, число, буква и тд..). 

Новый массив необходимо записать в переменную `result`.

**Sample Input 1:**

```
[2,3,"а",1,"б",4,"д","г"]
```

**Sample Output 1:**

```
[1,"а",2,"б",3,"г",4,"д"]
```

**Sample Input 2:**

```
[20,3,"a",1,"b",4,"q","g","w","z",5]
```

**Sample Output 2:**

```
[1,"a",3,"b",4,"g",5,"q",20,"w","z"]
```
