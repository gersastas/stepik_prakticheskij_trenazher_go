У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`. 

Напишите код, проверяет является ли массив `data` отсортированным или нет и записывает логический результат в переменную `result`.

**Sample Input 1:**

```
[1, 2, 3, 4, 5]
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
[1, 3, 2, 5, 4]
```

**Sample Output 2:**

```
false
```
