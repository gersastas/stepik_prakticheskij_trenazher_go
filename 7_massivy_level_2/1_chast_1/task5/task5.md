У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`. 

Напишите код, который сопоставляет первое число в массиве с последним, второе число с предпоследним и т.д. и записывает результат в переменную `result`.

**Пример:**

[1,2,3,4]=(1,4),(2,3)[1,2,3,4]=(1,4),(2,3)

[1,2,3]=(1,3),(2,2)[1,2,3]=(1,3),(2,2)

[]=()[]=()

 

**Важно!**

1. Если массив имеет нечетную длину, дважды повторите средний элемент для последней пары.
2. Возвращайте пустые ()(), если входящий массив является пустым.

**Sample Input 1:**

```
[1,2,3,4]
```

**Sample Output 1:**

```
(1,4),(2,3)
```

**Sample Input 2:**

```
[1,2,3]
```

**Sample Output 2:**

```
(1,3),(2,2)
```

**Sample Input 3:**

```
[]
```

**Sample Output 3:**

```
()
```
