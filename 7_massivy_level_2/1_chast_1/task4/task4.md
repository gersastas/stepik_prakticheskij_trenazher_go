У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`. 

Напишите код, который возвращает сумму пропущенных нечетных чисел из массива `data` и записывает результат в переменную `result`.

Например: 

[1,2,5,8]=3+7=10[1,2,5,8]=3+7=10

[1,2,3]=0[1,2,3]=0

**Sample Input:**

```
[1, 2, 5, 8]
```

**Sample Output:**

```
10
```
