У вас есть переменная `data` которая содержит входные пользовательские данные.

Напишите код, который проходит по массиву `data` и создает новый массива с элементами исходного списка, хранящимися в вложенных массивах. Элементы с одинаковым значением должны находиться в одном вложенном массиве. 

**Важно!**

- Вложенные массивы должны быть созданы в порядке первого появления каждого элемента в массиве `data`.

Новый массив необходимо записать в переменную `result`.

**Sample Input 1:**

```
[4,3,3,4,2,2,1,1,10,10,1,10]
```

**Sample Output 1:**

```
[[4,4],[3,3],[2,2],[1,1,1],[10,10,10]]
```

**Sample Input 2:**

```
["книга","броня","свиток","стрела","стрела","броня","книга","ключ"]
```

**Sample Output 2:**

```
[["книга","книга"],["броня","броня"],["свиток"],["стрела","стрела"],["ключ"]]
```
