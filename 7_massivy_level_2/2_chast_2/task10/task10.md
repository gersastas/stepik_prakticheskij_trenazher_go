У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`. 

Напишите код, который заменяет наибольший четный элемент массива и поменять его местами с наименьшим нечетным элементом. Если одного из таких элементов нет, то всем элементам массива присвоить значение, равное нулю.

Результат записать в переменную `result`. 

**Sample Input 1:**

```
[3, 7, 2, 5, 1, 9]
```

**Sample Output 1:**

```
[3,7,1,5,2,9]
```

**Sample Input 2:**

```
[1, 2, 3, 4, 6, 8]
```

**Sample Output 2:**

```
[8,2,3,4,6,1]
```
