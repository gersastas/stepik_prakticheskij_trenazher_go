У вас есть переменные `data`, `shift`, которые содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`. 

`shift` - сдвиг.

Напишите код, который выполняет кольцевой циклический сдвиг влево на значение переменной `shift`.

Новый список необходимо записать в переменную `result`.

**Sample Input 1:**

```
[1, 2, 3, 4, 5, 6] | 1
```

**Sample Output 1:**

```
[2,3,4,5,6,1]
```

**Sample Input 2:**

```
[1, 2, 3, 4, 5, 6] | 2
```

**Sample Output 2:**

```
[3,4,5,6,1,2]
```
