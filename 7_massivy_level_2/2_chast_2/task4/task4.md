У вас есть переменные `data`, `shift`, которые содержит входные пользовательские данные.

`data` - двумерный массив из элементов типа данных `int`. 

`shift` - сдвиг.

Напишите код, который выполняет кольцевой циклический сдвиг влево на значение переменной `shift`.

Новый массив необходимо записать в переменную `result`.

Например:

```javascript
// Исходный двумерный массив

[
  [1,2,3],
  [1,2,3],
  [1,2,3]
]

// Двумерный массив с циклическим сдвигом влево на 1

[
  [2,3,1],
  [2,3,1],
  [2,3,1]
]
                  
```

**Sample Input:**

```
[[1,2,3],[1,2,3]] | 1
```

**Sample Output:**

```
[[2,3,1],[2,3,1]]
```
