У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который определяет какой символ в строке `message` встречается раньше: `[` или `]` и записывает результат в переменную `result`. 

- Если в строке `message` нет символов `[` и `]` тогда записываем в `result` сообщение: `В строке нет символов [ и ]`
- Если в строке `message` нет символа `[` тогда записываем в `result` сообщение: `В строке нет символа [`
- Если в строке `message` нет символа `]` тогда записываем в `result` сообщение: `В строке нет символа ]`
- Если в строке `message` символ `[` встречается раньше символа `]` тогда записываем в `result` сообщение:
  `Символ [ встречается раньше символа ]`
- Если в строке `message` символ `]` встречается раньше символа `[` тогда записываем в `result` сообщение:
  `Символ ] встречается раньше символа [`

**Sample Input 1:**

```
Всегда делись тем, чему ты научился — Йода
```

**Sample Output 1:**

```
В строке нет символов [ и ]
```

**Sample Input 2:**

```
Всегда [делись тем, чему ты научился — Йода
```
