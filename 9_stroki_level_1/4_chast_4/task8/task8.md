У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который удаляет в строке `message` все буквы `x` за которыми следует `abc` и записывает результат в переменную `result`. 

**Важно!**

- `abc` не должно быть в итоговой строке.

**Sample Input 1:**

```
xabcxx
```

**Sample Output 1:**

```
xx
```

**Sample Input 2:**

```
xabcxxabcxx
```

**Sample Output 2:**

```
xxx
```
