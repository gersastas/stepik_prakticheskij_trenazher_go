У вас есть переменные `message1`, `message2`, которые принимают входные пользовательские данные.

Напишите код, который определяет содержится ли меньшая по длине строка в большей записывает логический результат в переменную `result`.

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.
- Учитывайте регистр `A != a`

**Sample Input 1:**

```
Hello World | World
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
Лия | Привет Лия
```

**Sample Output 2:**

```
true
```
