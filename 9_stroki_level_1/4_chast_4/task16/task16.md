У вас есть переменная `path`, которая содержит входные пользовательские данные.

`path` - полный путь файла в unix формате. 

Напишите код, который находит расширение файла и записывает результат в переменную `result`.

**Sample Input 1:**

```
/Users/lia/hello-world/hello-world.js
```

**Sample Output 1:**

```
js
```

**Sample Input 2:**

```
/hello-world/foo.html
```

**Sample Output 2:**

```
html
```
