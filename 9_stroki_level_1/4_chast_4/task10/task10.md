У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который находит наибольшее количество идущих подряд цифр в строке `message` и записывает результат в переменную `result`. 

**Sample Input:**

```
Lorem ipsum dolor sit 1234 amet, consectetur adipiscing 56789 elit.
```

**Sample Output:**

```
5
```
