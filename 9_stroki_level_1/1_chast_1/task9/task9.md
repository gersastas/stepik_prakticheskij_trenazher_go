У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который проверяет начинается ли строка в переменной `message` с `https://` и записывает логический результат в переменную `result`.

**Sample Input 1:**

```
https://awilum.ru
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
http://awilum.ru
```

**Sample Output 2:**

```
false
```
