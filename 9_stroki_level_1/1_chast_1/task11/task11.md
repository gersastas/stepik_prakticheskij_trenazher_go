У вас есть переменные `search`, `message` которые содержат входные пользовательские данные.

Напишите код, который проверяет содержит ли строка в переменной `message` строку из переменной `search` и записывает логический результат в переменную `result`.

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.

**Sample Input 1:**

```
одежду | Учитесь выбирать свои мысли, как выбираете в шкафу одежду каждый день.
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
приставку | Учитесь выбирать свои мысли, как выбираете в шкафу одежду каждый день.
```

**Sample Output 2:**

```
false
```
