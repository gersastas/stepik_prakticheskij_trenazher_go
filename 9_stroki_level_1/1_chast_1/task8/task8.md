У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который проверяет заканчивается ли строка в переменной `message` на символ `/` и записывает логический результат в переменную `result`.

**Sample Input 1:**

```
https://awilum.ru/
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
https://awilum.ru
```

**Sample Output 2:**

```
false
```
