У вас есть переменная `words`, которая содержит входные пользовательские данные.

`words` - список слов.

Напишите код, который создает новым список букв из списка слов `words` и записывает результат в переменную `result`. 

**Sample Input:**

```
["apple", "banana", "cherry"]
```

**Sample Output:**

```
["a","p","p","l","e","b","a","n","a","n","a","c","h","e","r","r","y"]
```
