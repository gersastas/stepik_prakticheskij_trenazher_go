У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который подсчитывает количество слов в строке `message`, которые начинаются и заканчиваются с одниковой буквы (регистр неважен) и записывает результат в переменную `result`. 

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей

**Sample Input 1:**

```
Привет Анна
```

**Sample Output 1:**

```
1
```

**Sample Input 2:**

```
Привет Лия
```

**Sample Output 2:**

```
0
```
