У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который переводит значение строки `message` из `UpperCamelCase` в `snake_case` и записывает результат в переменную `result`.

**Sample Input:**

```

```

**Sample Output:**

```

```
