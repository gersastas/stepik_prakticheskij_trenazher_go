У вас есть переменная `words`, которая содержит входные пользовательские данные.

`words` - список слов.

Напишите код, который создает новый список крайних (первая, последняя) букв слов из списка слов `words` и записывает результат в переменную `result`. 

**Sample Input:**

```
["apple", "banana", "cherry"]
```

**Sample Output:**

```
["a","e","b","a","c","y"]
```
