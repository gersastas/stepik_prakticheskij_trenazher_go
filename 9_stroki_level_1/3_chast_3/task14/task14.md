У вас есть переменная `words`, которая содержит входные пользовательские данные.

`words` - список слов.

Напишите код, который создает новый список центральных букв нечетных слов из списка слов `words` и записывает результат в переменную `result`. 

**Sample Input 1:**

```
["apple", "banana"]
```

**Sample Output 1:**

```
["p"]
```

**Sample Input 2:**

```
["apple", "banana", "apple"]
```

**Sample Output 2:**

```
["p","p"]
```
