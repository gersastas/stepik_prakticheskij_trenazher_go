У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который маскирует все символы в строке  `message` символом `#` за исключением 4 последних символов и записывает результат в переменную `result`.

**Важно!** Если длина строки равна 4 и менее символов, тогда маскировку не делаем, а возвращаем строку без изменений.

**Sample Input 1:**

```
TheNinaProject
```

**Sample Output 1:**

```
##########ject
```

**Sample Input 2:**

```
nina
```

**Sample Output 2:**

```
nina
```
