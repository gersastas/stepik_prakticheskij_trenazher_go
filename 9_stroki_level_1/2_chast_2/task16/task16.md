У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который изменяет порядок букв в каждом слове переменной `message` на отсортированный в алфавитном порядке по возрастанию и записывает результат в переменную `result`.

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.

**Sample Input:**

```
Самый полный курс для начинающих программистов
```

**Sample Output:**

```
Саймы йлнопы крсу для ааииннхчщю авгиммоопррст
```
