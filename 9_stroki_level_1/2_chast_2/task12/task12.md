У вас есть переменная `message`, которая принимает входные пользовательские данные.

Напишите код, который проверяет нет ли в строке слов дубликатов и записывает логический результат в переменную `result`. 

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.
- Переводить текст в нижний регистр перед сравнением. 

**Sample Input 1:**

```
Лия Лия Привет
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
лия Лия Привет
```

**Sample Output 2:**

```
true
```

**Sample Input 3:**

```
Кот собака
```

**Sample Output 3:**

```
false
```
