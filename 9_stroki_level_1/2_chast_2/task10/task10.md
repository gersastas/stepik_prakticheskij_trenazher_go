У вас есть переменная `message`, которая принимает входные пользовательские данные.

Напишите код, который который подсчитывает количество букв внутри `[]` и записывает результат через запятую в переменную `result`. 

 

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.
- Формат входящей строки такой: `[слово][слово][слово][слово]...`

**Sample Input 1:**

```
[Лия][Парфенова]
```

**Sample Output 1:**

```
3, 9
```

**Sample Input 2:**

```
[Tom][]
```

**Sample Output 2:**

```
3, 0
```
