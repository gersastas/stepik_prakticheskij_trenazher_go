У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который выбирает все строчные буквы в переменной `message` и записывает через запятую результат в переменную `result`.

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.

**Sample Input 1:**

```
Лия
```

**Sample Output 1:**

```
и, я
```

**Sample Input 2:**

```
ПрИВет
```

**Sample Output 2:**

```
р, е, т
```

**Sample Input 3:**

```
FooBar
```

**Sample Output 3:**

```
o, o, a, r
```
