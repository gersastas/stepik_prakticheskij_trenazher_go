У вас есть переменная `message`, которая принимает входные пользовательские данные.

Напишите код, который проверяет есть ли повторяющиеся подряд буквы в слове и записывает логический результат в переменную `result`.

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.

**Sample Input 1:**

```
Анна
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
Лия
```

**Sample Output 2:**

```
false
```
