У вас есть переменные `cases`, `message`, которые принимают входные пользовательские данные.

Напишите код, который разбивает слово на части, размер которых указан в переменной `cases` и возвращает части слова разделенные запятыми в переменную `result`. 

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.
- Значение переменой `cases` равно 2 или 1.
- Если слово не может быть разбито на две равные части, тогда записываем сообщением "Слово не может быть равномерно разделено." в переменную `result`. 
- Если `cases = 1` тогда возвращаем слово целиком без изменений.

**Sample Input 1:**

```
2 | Привет
```

**Sample Output 1:**

```
При, вет
```

**Sample Input 2:**

```
2 | Лия
```

**Sample Output 2:**

```
Слово не может быть равномерно разделено.
```
