У вас есть переменная `message`, которая принимает входные пользовательские данные.

Напишите код, который находит первую повторяющуюся букву и записывает результат в переменную `result`. Если повторяющихся букв нет, тогда записываем пустую строку в переменную `result`.

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.
- Тесты чувствительны к регистру. 

**Sample Input 1:**

```
Сортировка
```

**Sample Output 1:**

```
о
```

**Sample Input 2:**

```
Практика
```

**Sample Output 2:**

```
а
```
