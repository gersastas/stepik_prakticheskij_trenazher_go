У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который удаляет все гласные буквы из переменной `message` и записывает результат в переменную `result`.

**Гласные буквы:** а,у,о,ы,э,я,ю,ё,и,е

**Важно!**

- Учитывайте то что ваш код должен работать с кириллицей.
- Тесты чувствительны к регистру. 

**Sample Input:**

```
Привет
```

**Sample Output:**

```
Првт
```
