У вас есть переменные `n`, `k` которые содержат входные пользовательские данные.

Напишите код, который находит количество цифр `k` в записи всех натуральных чисел от 1 до `n` и записывает результат в переменную `result`.

Например:

```markdown
n = 15, k = 5

5 => 5
15 => 5

Итого: 2
                  
n = 20, k = 2

2 => 2
12 => 2
20 => 2
21 => 2
22 => 2
22 => 2

Итого: 6
                  
```

**Sample Input 1:**

```
5 | 5
```

**Sample Output 1:**

```
1
```

**Sample Input 2:**

```
15 | 5
```

**Sample Output 2:**

```
2
```

**Sample Input 3:**

```
22 | 2
```

**Sample Output 3:**

```
6
```
