У вас есть переменные `n`, `p` которые содержат входные пользовательские данные.

Напишите код, который вычисляет процент от заданного числа.

`n` - число.
`p` - процент.

Результат округлить до одного знака после запятой и записать в переменную `result`.

**Sample Input:**

```
200 | 25
```

**Sample Output:**

```
50.0
```
