У вас есть переменная `n`, которая содержит входные пользовательские данные.

Напишите код, который переводит [десятичное](https://ru.wikipedia.org/wiki/Десятичная_система_счисления) число `n` в [шестнадцатеричное](https://ru.wikipedia.org/wiki/Шестнадцатеричная_система_счисления) и записывает результат в переменную `result`.

**Важно!** Шестнадцатеричное значение должно быть переведено в верхний регистр

**Sample Input:**

```
255
```

**Sample Output:**

```
FF
```
