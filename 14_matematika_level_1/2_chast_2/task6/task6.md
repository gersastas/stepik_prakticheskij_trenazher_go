У вас есть переменная `n`, которая содержит входные пользовательские данные.

Напишите код, который переводит [двоичное](https://ru.wikipedia.org/wiki/Двоичная_система_счисления) число `n` в [десятичное](https://ru.wikipedia.org/wiki/Десятичная_система_счисления) и записывает результат в переменную `result`.

**Sample Input:**

```
101
```

**Sample Output:**

```
5
```
