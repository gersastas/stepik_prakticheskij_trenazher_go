У вас есть переменные `a`, `b`, которые содержат входные пользовательские данные.

Напишите код, который вычисляет наибольший общий делитель переменных `a`, `b`, и записывает результат в переменную `result`. 

**Sample Input 1:**

```
12 | 18
```

**Sample Output 1:**

```
6
```

**Sample Input 2:**

```
4 | 36
```

**Sample Output 2:**

```
4
```
