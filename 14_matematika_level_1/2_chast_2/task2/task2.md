У вас есть переменная `n`, которая содержит входные пользовательские данные.

Напишите код, который находит произведение первой и последней цифры числа `n` и записывает результат в переменную `result`.

**Sample Input 1:**

```
128
```

**Sample Output 1:**

```
Произведение первой и последней цифры числа 128 равно 8
```

**Sample Input 2:**

```
256
```

**Sample Output 2:**

```
Произведение первой и последней цифры числа 256 равно 12
```
