У вас есть переменная `n`, которая содержит входные пользовательские данные.

Напишите код, который переводит [десятичное](https://ru.wikipedia.org/wiki/Десятичная_система_счисления) число `n` в [троичную](https://ru.wikipedia.org/wiki/Троичная_система_счисления) и записывает результат в переменную `result`.

**Sample Input:**

```
10
```

**Sample Output:**

```
101
```
