У вас есть переменная `message`, которая содержит входные пользовательские данные.

`message` содержит простое математическое выражение состоящие из двух чисел. 

Напишите код, вычисляет математическое выражение в переменной `message` и записывает результат в переменную `result`.

Например, если `message = "2 + 2"`, тогда `result = "2 + 2 = 4"`

Например, если `message = "2 - 2"`, тогда `result = "2 - 2 = 0"`

Например, если `message = "2 x 2"`, тогда `result = "2 x 2 = 4"`

Например, если `message = "2 / 2"`, тогда `result = "2 / 2 = 1"`

**Sample Input:**

```
2 + 2
```

**Sample Output:**

```
2 + 2 = 4
```
