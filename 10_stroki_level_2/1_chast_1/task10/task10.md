У вас есть переменные `message1`, `message2`, которые содержат входные пользовательские данные.

`message1`, `message2` - две строки, состоящие из слов, разделенных пробелами.

Напишите код, который формирует новую строку, состоящую из слов, которые:

1. встречаются хотя бы в одной строке, если нет тогда на это место записываем пустой результат.
2. встречаются только в первой строке, если нет тогда на это место записываем пустой результат.
3. встречаются только в одной из строк, если нет тогда на это место записываем пустой результат.

Новая строка должна быть следующего формата: `1 | 2 | 3`

Результат записать в переменную `result`.

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.
- Учитывайте регистр. `A != a`

**Sample Input 1:**

```
Джейн Макс Лукас | Лукас Дастин Стив
```

**Sample Output 1:**

```
Лукас | Джейн, Макс | Джейн, Макс, Дастин, Стив
```

**Sample Input 2:**

```
Джейн Макс Лукас Билли Робин Джойс | Лукас Дастин Стив
```

**Sample Output 2:**

```
Лукас | Джейн, Макс, Билли, Робин, Джойс | Джейн, Макс, Билли, Робин, Джойс, Дастин, Стив
```
