У вас есть переменная `message`, которая содержит входные пользовательские данные.

`message` - строка, которая содержит два слова.

Напишите код, который находит символы, встречающиеся только один раз в двух словах строки `message`

Результат записать через запятую (в то порядке в котором символы были найдены) в переменную `result`.

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.
- Учитывайте регистр. `A != a`

**Sample Input 1:**

```
Hello World
```

**Sample Output 1:**

```
H, e, W, r, d
```

**Sample Input 2:**

```
Привет Мир
```

**Sample Output 2:**

```
П, в, е, т, М
```
