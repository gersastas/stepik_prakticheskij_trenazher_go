У вас есть переменная `message`, которая содержит входные пользовательские данные.

`message` - строка, которая содержит буквы и скобки `(`, `)`, `[`, `]`, `{`, `}`

Напишите код, который проверяет если скобки расставлены правильно (то есть каждой открывающей скобки соответствует закрывающая того же вида), то записывает логический результат `True`, иначе вернуть `False` в в переменную `result`.

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.

**Sample Input 1:**

```
[{(Hello World)}]
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
[{([Hello] {World})}]
```

**Sample Output 2:**

```
true
```

**Sample Input 3:**

```
[{([(He){llo}] {[World]})}]
```

**Sample Output 3:**

```
true
```

**Sample Input 4:**

```
[{(Hello World){}[]
```

**Sample Output 4:**

```
false
```

**Sample Input 5:**

```
[{(Hello){}[World]
```

**Sample Output 5:**

```
false
```
