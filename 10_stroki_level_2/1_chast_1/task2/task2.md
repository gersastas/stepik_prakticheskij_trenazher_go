У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который **извлекает** **первых 5 длинных** слов (длина которых >= 5 букв) из переменной `message` и преобразует их в хэштеги и записывает результат в переменную `result`.

**Важно!**

1. Хэштеги должны состоять только из буквы русского и английского алфавита. 
2. Каждый хэштег должен начинаться с символа `#`
3. Все хэштеги должны быть в нижнем регистре.

**Sample Input 1:**

```
Игра престолов - сериал, основанный на романах Джорджа Мартина, рассказывающий о борьбе за власть в вымышленном мире Вестероса
```

**Sample Output 1:**

```
#престолов #сериал #основанный #романах #джорджа
```

**Sample Input 2:**

```
Гладиатор - исторический эпос о римском генерале, который борется за свою свободу и мести
```

**Sample Output 2:**

```
#гладиатор #исторический #римском #генерале #который
```
