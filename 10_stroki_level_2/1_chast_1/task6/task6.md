У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который находит скрытые слова в строке `message` и записывает каждую букву скрытых слов в виде строки через нижний пробел `_` в переменную `result`.

**Важно!**

- Скрытые слова не содержат буквы `f`, `o` или `g` (как в нижнем так и в верхнем регистре).
- Скрытые слова всегда начинаются с большой буквы.
- Строка содержит только латинские буквы.

**Sample Input 1:**

```
fogfogFFfooooffTogffreogffesGgfOogfog
```

**Sample Output 1:**

```
T_r_e_e_s
```

**Sample Input 2:**

```
fogfogFFfooooffTogffreogffesGgfOogfogTrees
```

**Sample Output 2:**

```
T_r_e_e_s_T_r_e_e_s
```
