У вас есть переменные `message1`, `message2`, которые содержат входные пользовательские данные.

Напишите код, который реализует функцию `isAnagram()`, которая принимает два аргумента `message1` и `message2`, проверяет, являются ли две строки [анаграммами](https://ru.wikipedia.org/wiki/Анаграмма), причем регистр букв не имеет значения. Учитываются лишь символы; пробелы или знаки препинания в расчет не берутся.

Логический результат записать в переменную `result`.

**Sample Input 1:**

```
нора | рано
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
нора | кора
```

**Sample Output 2:**

```
false
```
