У вас есть переменные `message1`, `message2`, которые содержат входные пользовательские данные.

`message1`, `message2` - две строки, состоящие из слов, разделенных пробелами.

Напишите код, который определяет первое самое длинное общее слово двух строк `message1`, `message2`.

Результат записать в переменную `result` в формате: `Самое длинное общее слово: СЛОВО`

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.
- Учитывайте регистр. `A != a`

**Sample Input 1:**

```
The quick brown fox jumps over the lazy dog | A quick brown dog jumps over the lazy fox
```

**Sample Output 1:**

```
Самое длинное общее слово: quick
```

**Sample Input 2:**

```
Красивая цветочная композиция стоит на столе | Цветочная композиция привлекает внимание своим разнообразием
```

**Sample Output 2:**

```
Самое длинное общее слово: композиция
```

### Напишите программу. Тестируется через stdin → stdout
