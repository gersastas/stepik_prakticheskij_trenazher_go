У вас есть переменные `message1`, `message2`, которые содержат входные пользовательские данные.

Напишите код, который проверяет является ли значение перменной `message2` обращенным (reverse) значению перменной `message1` и записывает логический результат в переменную `result`.

**Важно!**

- Учитывайте то что ваш код должен работать как с кириллицей так и с латиницей.

**Sample Input 1:**

```
Привет | тевирП
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
Привет | Лия
```

**Sample Output 2:**

```
false
```
