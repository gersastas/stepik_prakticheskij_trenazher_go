У вас есть переменные `role`, которая содержит входные пользовательские данные.

Напишите код, который в зависимости от значения переменной `role` записывает соответствующий результат в переменную `result`.

1 — admin
2 — moderator
3 — user
default — guest

**Sample Input 1:**

```
1
```

**Sample Output 1:**

```
admin
```

**Sample Input 2:**

```
2
```

**Sample Output 2:**

```
moderator
```

**Sample Input 3:**

```
3
```

**Sample Output 3:**

```
user
```
