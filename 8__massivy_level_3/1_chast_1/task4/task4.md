У вас есть переменная `grid` которая содержит входные пользовательские данные.

`grid` - двухмерный массив из элементов типа данных `int`. 

Напишите код, который подсчитывает количество блоков воды, блоков земли, блоков кораблей и блоков вулканов в двумерном массиве `grid` и записывает результат в переменную `result`.

`0` - блок воды на карте.
`1` - блок земли на карте.
`2` - блок корабля на карте.
`3` - блок вулкана на карте.

Размер двумерного массива 4х4 

Например:

**блоков воды: 7, блоков земли: 4, блоков кораблей: 4, блоков вулканов: 1**

```javascript
[
  [1,0,0,2],
  [1,2,3,0],
  [1,0,0,0],
  [1,2,0,2]
]
                  
```

![img](img.png)

**Sample Input:**

```
[[1,0,0,2],[1,2,3,0],[1,0,0,0],[1,2,0,2]]
```

**Sample Output:**

```
блоков воды: 7, блоков земли: 4, блоков кораблей: 4, блоков вулканов: 1
```
