У вас есть переменная `n`, которая содержит входные пользовательские данные.

`n` - натуральное число.

Напишите код, который определяет, будет ли это число: четным, кратным 6.

Логический результат записать в переменную `result`.

**Sample Input 1:**

```
6
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
7
```

**Sample Output 2:**

```
false
```

**Sample Input 3:**

```
12
```

**Sample Output 3:**

```
true
```
