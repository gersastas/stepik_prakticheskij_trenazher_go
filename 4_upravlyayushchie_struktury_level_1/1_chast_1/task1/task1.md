У вас есть переменная `n`, которая содержит входные пользовательские данные.

`n` - натуральное число.

Напишите код, который определяет, будет ли это число: нечётным, кратным 7.

Логический результат записать в переменную `result`.

**Sample Input 1:**

```
21
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
7
```

**Sample Output 2:**

```
true
```

**Sample Input 3:**

```
14
```

**Sample Output 3:**

```
false
```
