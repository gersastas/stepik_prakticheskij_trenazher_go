У вас есть переменная `files` которая содержит входные пользовательские данные.

`files` - массив из элементов типа данных `string`.

Напишите код, который находит все файлы в массив `files`, которые начинаются с `image` и записывает новый массив в переменную `result`.

**Sample Input:**

```
["image1.png", "index.php", "buttons.js", "image4.gif"]
```

**Sample Output:**

```
["image1.png","image4.gif"]
```
