У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`. 

Напишите код, который находит наиболее часто встречающийся элемент в массиве целых чисел.

Результат записать в переменную `result`. 

**Sample Input 1:**

```
[1, 2, 3, 1, 2, 5, 4, 1, 2, 2]
```

**Sample Output 1:**

```
2
```

**Sample Input 2:**

```
[1, 2, 3, 1, 2, 5, 4, 1, 1, 2]
```

**Sample Output 2:**

```
1
```
