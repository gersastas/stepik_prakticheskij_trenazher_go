У вас есть переменныe `data1`, `data2`, `data3`, которые содержат входные пользовательские данные.

`data1` - массив из элементов типа данных `int`.

`data2` - массив из элементов типа данных `int`.

`data3` - массив из элементов типа данных `int`.

Напишите код, который сравнивает три списка `data1`, `data2`, `data3` и записывает результат в переменную `result`.

Сообщение в переменой `result` : **Массивы одинаковые** или **Массивы разные**

**Sample Input 1:**

```
[1,2,3] | [1,2,3] | [1,2,3] 
```

**Sample Output 1:**

```
Массивы одинаковые
```

**Sample Input 2:**

```
[4,5,7] | [1,2,3] | [7,8,9] 
```

**Sample Output 2:**

```
Массивы разные
```
