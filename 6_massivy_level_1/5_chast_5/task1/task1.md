У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`. Элементы 0 и одна 1.

Напишите код, который определяет количество 0 до и после 1 и записывает результат в переменную `result`.

**Sample Input:**

```
[0,0,0,0,0,1,0,0,0]
```

**Sample Output:**

```
Количество нулей перед единицей: 5, Количество нулей после единицы: 3
```
