У вас есть переменная `length` которая содержит входные пользовательские данные.

`length` - это длина массива.

Напишите код, который формирует убывающий массив из целых чисел, делящихся на 3 и записывает результат в переменную `result`.

**Sample Input 1:**

```
2
```

**Sample Output 1:**

```
[6,3]
```

**Sample Input 2:**

```
5
```

**Sample Output 2:**

```
[15,12,9,6,3]
```
