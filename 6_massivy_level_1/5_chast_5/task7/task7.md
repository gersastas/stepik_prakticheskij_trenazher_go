У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`. 

Напишите код, который находит количество:

1. уникальных чисел
2. дублированных чисел 
3. нулей
4. четных чисел (кроме 0)
5. нечетных чисел

Результат записать через запятую в переменную `result`. 

Формат записи в переменную `result`: 

```javascript
uniqueCount, duplicateCount, zeroCount, evenCount, oddCount
                  
```

**Sample Input 1:**

```
[1, 2, 3, 1, 2, 5, 4, 1, 2, 0, 0, 0]
```

**Sample Output 1:**

```
3, 3, 3, 4, 5
```

**Sample Input 2:**

```
[0, 1, 2, 3, 0, 2, 9, 6, 8, 3, 2, 1]
```

**Sample Output 2:**

```
3, 4, 2, 5, 5
```
