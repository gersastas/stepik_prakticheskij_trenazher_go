У вас есть переменные `n` и `items`, которые содержат входные пользовательские данные.

`items` - массив из элементов типа данных `int`.

Напишите код, который перемещает элементы массива `items` из начала массива в конец списка и записывается результат в переменную `result`.

`n` - число элементов которые необходимо переместить.

**Sample Input:**

```
3 | [1, 3, 2, 5, 9, 8, 1, 2]
```

**Sample Output:**

```
5, 9, 8, 1, 2, 1, 3, 2
```
