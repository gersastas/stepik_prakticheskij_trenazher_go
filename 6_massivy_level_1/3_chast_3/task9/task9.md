У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов произвольного типа данных `interface{}`.

Напишите код, который проверяет все элементы в массиве `data` и записывает в новый массив только логические значения `true` и `false`.

Новый массив записать через запятую в переменную `result`.

**Sample Input:**

```
[42, "Макс", false, 3.14, true]
```

**Sample Output:**

```
false, true
```
