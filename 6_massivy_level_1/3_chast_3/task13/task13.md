У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`.

Напишите код, который определяет, имеются ли в массиве два подряд идущих нуля и записывает логический результат в переменную `result`.

**Sample Input 1:**

```
[1, 2, 3, 0, 1, 0]
```

**Sample Output 1:**

```
false
```

**Sample Input 2:**

```
[0, 0, 3, 0, 1, 0]
```

**Sample Output 2:**

```
true
```
