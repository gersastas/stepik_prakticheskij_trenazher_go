У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов.

Напишите код, который проверяет все ли элементы в массиве `data` одинаковые и записывает логический результат в переменную `result`.

**Sample Input 1:**

```
[42, 42, 42, 42]
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
["###", "###", "###", "###"]
```

**Sample Output 2:**

```
true
```

**Sample Input 3:**

```
["###", "###", "###", "$$$"]
```

**Sample Output 3:**

```
false
```
