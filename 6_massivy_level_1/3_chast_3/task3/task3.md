У вас есть переменная `message` которая содержит входные пользовательские данные.

Напишите код, который:

1. Читает строку `message` вида: `a2b3c1`
2. Воссоздает массив: `a2b3c1` -> `["a","a","b","b","b","c"]`
3. Записывает воссозданный массив через запятую в переменную `result`.

**Sample Input:**

```
a2b3c1
```

**Sample Output:**

```
a, a, b, b, b, c
```
