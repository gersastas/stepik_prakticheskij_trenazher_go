У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов произвольного типа данных.

Напишите код, который проверяет все элементы в массиве `data` и записывает в новый массив только числа.

Новый список записать через запятую в переменную `result`.

**Sample Input:**

```
[42, "Лия", false, 3.14, true]
```

**Sample Output:**

```
42, 3.14
```
