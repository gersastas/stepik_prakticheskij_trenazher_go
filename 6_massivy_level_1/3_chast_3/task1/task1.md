У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`.

Напишите код, который проходит по массиву `data`, удаляет все нулевые элементы массива и записывает новый массив в переменную `result`.

**Sample Input:**

```
[0,1,0,1,1,1,0,1]
```

**Sample Output:**

```
[1,1,1,1,1]
```
