У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`.

Напишите код, который отображает зеркально массив `data` в новом массиве и записывает результат через запятую в переменную `result`.

**Sample Input 1:**

```
[1, 2, 3]
```

**Sample Output 1:**

```
1, 2, 3, 2, 1
```

**Sample Input 2:**

```
[1, 2, 3, 4, 5]
```

**Sample Output 2:**

```
1, 2, 3, 4, 5, 4, 3, 2, 1
```
