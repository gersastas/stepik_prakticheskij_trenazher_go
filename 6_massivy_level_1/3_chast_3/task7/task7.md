У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов произвольного типа данных.

Напишите код, который суммирует числа в массиве `data` между элементами `start` и `end` и записывает результат в переменную `result`.

Если в массиве нет элементов `start` и `end` тогда в переменную `result` записываем: `-1`

**Важно!**

Элемент `start` всегда должен идти перед элементом `end`. Eсли это условия не соблюдено, тогда в переменную `result` записываем сообщение: `-1`

**Sample Input 1:**

```
[1, 2, "start", 2, 2, 1, "end", 1, 5]
```

**Sample Output 1:**

```
5
```

**Sample Input 2:**

```
[2, 2, 1, "end", 1, 5]
```

**Sample Output 2:**

```
-1
```

**Sample Input 3:**

```
[2, 2, 1, "start", 1, 5]
```

**Sample Output 3:**

```
-1
```
