У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`.

Напишите код, который принимает массив чисел `data` и возвращает новый массив, в котором все отрицательные числа заменены на 0 и записывает новый массив в переменную `result`.

**Sample Input:**

```
[1, 3, 0, -1, 2, 5]
```

**Sample Output:**

```
[1,3,0,0,2,5]
```
