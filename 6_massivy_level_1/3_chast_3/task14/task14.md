У вас есть переменная `data` которая содержит входные пользовательские данные.

`data` - массив из элементов типа данных `int`.

Напишите код, который вместо каждого элемента с нулевым значением поставляет сумму двух предыдущих элементов массива и записывает результат в виде нового массива в переменную `result`.

**Sample Input:**

```
[1, 0, 2, 0, 3, 4, 0]
```

**Sample Output:**

```
[1,0,2,2,3,4,7]
```
