У вас есть переменная `email`, которая содержит входные пользовательские данные.

Напишите код, который валидирует `email` и записывает логический результат в переменную `result`.

Условия:

1. Email должен содержать символ "@", который разделяет имя пользователя и домен.
2. Имя пользователя должно содержать только буквы (a-z, A-Z), цифры (0-9), дефисы (-), точки (.) и нижние подчеркивания (_).
3. Имя пользователя не должно начинаться или заканчиваться на дефис, точку или нижнее подчеркивание.
4. Домен должен содержать только буквы (a-z, A-Z), цифры (0-9) и точки (.).
5. Домен не может содержать более одной точки подряд и не может начинаться или заканчиваться точкой.
6. Доменное имя должно содержать как минимум одну точку и не может быть длиннее 63 символов.

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input 1:**

```
lia@live.com
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
lialive.com
```

**Sample Output 2:**

```
false
```
