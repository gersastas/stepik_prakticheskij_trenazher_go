У вас есть переменная `cvv`, которая содержит входные пользовательские данные.

Напишите код, который валидирует CVV код для карты и записывает логический результат в переменную `result`.

CVV состоит строго из 3 цифр.

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input 1:**

```
123
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
12
```

**Sample Output 2:**

```
false
```

**Sample Input 3:**

```
a23
```

**Sample Output 3:**

```
false
```
