У вас есть переменная `pin`, которая содержит входные пользовательские данные.

Напишите код, который валидирует PIN код для банкомата и записывает логический результат в переменную `result`.

Банкоматы позволяют использовать 4 или 6 значные PIN-коды, PIN-коды не могут содержать ничего, кроме строго 4 или строго 6 цифр.

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input 1:**

```
1984
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
019840
```

**Sample Output 2:**

```
true
```
