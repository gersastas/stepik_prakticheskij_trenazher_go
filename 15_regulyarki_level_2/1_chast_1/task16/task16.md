У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который извлекает все хештеги из `message` и записывает результат через запятую в переменную `result`.

**Важно!** Если хештеги в сообщении не найдены, тогда в переменную `result` записываем сообщение: 
`Хештеги не найдены в сообщении.`

 

Условия валидного хештеги могут включать следующие:

1. Хэштег должен начинаться с символа `#`.
2. За символом `#` должен идти хотя бы один алфавитно-цифровой символ (буква или цифра).
3. Хэштег может содержать любое количество алфавитно-цифровых символов после символа `#`.
4. Хэштег может состоять из букв русского так и английского алфавита.
5. Хэштег не может содержать пробелов или других специальных символов, кроме алфавитно-цифровых символов.

Примеры валидных хэштегов, которые соответствуют данному регулярному выражению: `#hashtag`, `#hash_tag`, `#hash123`, `#tag`.

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input:**

```
Сегодня я провел отличное время на #пляже с #друзьями!
```

**Sample Output:**

```
#пляже, #друзьями
```
