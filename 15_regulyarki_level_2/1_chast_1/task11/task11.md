У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который извлекает телефонный номер формата **+7 (9хх) ххх-хх-хх** из `message` и записывает результат в переменную `result`.

**Важно!** Если телефонный номер в сообщении не найден, тогда в переменную `result` записываем сообщение: 
`Телефонный номер не найден в сообщении.`

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input 1:**

```
Позвонить по номеру +7 (980) 090-00-01 завтра в 9:49.
```

**Sample Output 1:**

```
+7 (980) 090-00-01
```

**Sample Input 2:**

```
Привет! Мой номер телефона +7 (912) 345-00-10. Свяжитесь со мной!
```

**Sample Output 2:**

```
+7 (912) 345-00-10
```
