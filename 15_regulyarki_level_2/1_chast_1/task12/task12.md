У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который извлекает номер карты формата **XXXX-XXXX-XXXX-XXXX** из `message` и записывает результат в переменную `result`.

**Важно!** Если номер карты в сообщении не найден, тогда в переменную `result` записываем сообщение: 
`Номер карты не найден в сообщении.`

 

Условия валидного номера карты:

1. Длина номера карты должна быть равна 16 цифрам
2. Формат номера карты: **XXXX-XXXX-XXXX-XXXX**

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input:**

```
Привет! Мой номер карты: 1234-5678-9012-3456. Воспользуйтесь им!
```

**Sample Output:**

```
1234-5678-9012-3456
```
