У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который извлекает все названия игровых жанров, заключенных в скобки из `message` и записывает результат через запятую в переменную `result`.

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input:**

```
Люблю игры в жанре (Actions) и (RPG)!
```

**Sample Output:**

```
Actions, RPG
```
