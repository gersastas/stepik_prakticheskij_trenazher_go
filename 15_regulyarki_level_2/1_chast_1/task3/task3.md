У вас есть переменная `cardnumber`, которая содержит входные пользовательские данные.

Напишите код, который валидирует `cardnumber` и записывает логический результат в переменную `result`.

Условия:

1. Длина номера карты должна быть равна 16 цифрам
2. Формат номера карты: XXXX-XXXX-XXXX-XXXX

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input 1:**

```
1111-2222-3333-4444
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
111-222-3333-4444
```

**Sample Output 2:**

```
false
```
