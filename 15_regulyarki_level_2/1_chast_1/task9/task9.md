У вас есть переменная `message`, которая содержит входные пользовательские данные.

Напишите код, который извлекает все названия игровых персонажей, заключенных в угловые скобки из `message` и записывает результат через запятую в переменную `result`.

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input:**

```
Мой любимый персонаж в "World of Warcraft" - <Тиранда> и в Red Dead Redemption 2 - <Артур Морган>.
```

**Sample Output:**

```
Тиранда, Артур Морган
```
