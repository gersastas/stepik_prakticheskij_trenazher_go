У вас есть переменная `password`, которая содержит входные пользовательские данные.

Напишите код, который валидирует `password` и записывает логический результат в переменную `result`.

Условия:

1. Пароль должен быть не менее 8 символов
2. Пароль должен содержать как минимум одну букву и одну цифру

**Подсказка!** Для разработки и отладки регулярных выражений используйте: [https://regex101.com](https://regex101.com/)

**Sample Input 1:**

```
qwerty123456
```

**Sample Output 1:**

```
true
```

**Sample Input 2:**

```
qwerty
```

**Sample Output 2:**

```
false
```

**Sample Input 3:**

```
qwerty12345642
```

**Sample Output 3:**

```
true
```

**Sample Input 4:**

```
42
```

**Sample Output 4:**

```
false
```
